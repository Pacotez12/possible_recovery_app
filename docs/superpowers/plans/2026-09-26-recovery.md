# POSsible Recovery Implementation Plan

> **For agentic workers:** Implement task-by-task. Steps use checkbox (`- [ ]`) syntax. **Do NOT commit** — Marco reviews and commits. Keep final reports to 2–3 lines.

**Goal:** Re-associate ~33,000 physically attached RFID labels (EPC) to CONMEBOL assets (SKU `AF-xxxxxx`) using Chainway C72 collectors, with several operators working at once.

**Architecture:** Laravel backend exposes `recovery/*` endpoints that are the single source of truth (transactional, idempotent by `client_uuid`, audited in `tag_matches`). A separate lightweight Flutter app reads one EPC via the C72 UHF module, gets the SKU from the label QR or keyboard, and calls the API, queueing offline.

**Tech Stack:** Laravel 10, Filament 3, PostgreSQL 16, tymon/jwt (backend). Flutter 3.47 (`/home/mbsegel/Proyectos/flutter/bin/flutter`), dio, sqflite, shared_preferences, mobile_scanner, Chainway `DeviceAPI_ver20250209_release.aar` (app).

Spec: `docs/superpowers/specs/2026-09-26-recovery-design.md`.

### Task A2: `RecoveryService` (business rules, testable without HTTP)

**Files:** Create `app/Services/RecoveryService.php`

```php
class RecoveryService
{
    public const EPC_REGEX = '/^[0-9A-F]{24}$/';

    public function normalizeEpc(string $epc): string { return strtoupper(trim($epc)); }
    public function normalizeSku(string $sku): string { return strtoupper(trim($sku)); }

    /** @return array{status:int, body:array} */
    public function assign(string $epc, string $sku, int $userId, ?string $deviceId, string $clientUuid): array
    {
        if ($existing = TagMatch::where('client_uuid', $clientUuid)->first()) {
            return $this->replay($existing);
        }
        $epc = $this->normalizeEpc($epc);
        $sku = $this->normalizeSku($sku);

        if (! preg_match(self::EPC_REGEX, $epc)) {
            return $this->reject($epc, $sku, $userId, $deviceId, $clientUuid, 'EPC inválido');
        }
        $product = Product::where('sku', $sku)->first();
        if (! $product) {
            return $this->reject($epc, $sku, $userId, $deviceId, $clientUuid, 'SKU no encontrado');
        }

        return DB::transaction(function () use ($epc, $sku, $product, $userId, $deviceId, $clientUuid) {
            $item = PhysicalItem::where('rfid_tag', $epc)->lockForUpdate()->first();

            if (! $item) {
                $locationId = ProductLocation::where('product_id', $product->id)->value('location_id');
                $item = new PhysicalItem([
                    'product_id' => $product->id, 'location_id' => $locationId,
                    'rfid_tag' => $epc, 'status' => 'en_stock', 'lot_number' => 'RECOVERY',
                ]);
                $item->printed_count = 1;
                $item->save();
                $this->audit($epc, $sku, $product->id, 'created', null, $item->id, $userId, $deviceId, $clientUuid);
                return ['status' => 201, 'body' => ['result' => 'created', 'sku' => $sku, 'description' => $product->description]];
            }

            if ((int) $item->product_id === (int) $product->id) {
                $this->audit($epc, $sku, $product->id, 'verified', null, $item->id, $userId, $deviceId, $clientUuid);
                return ['status' => 200, 'body' => ['result' => 'verified', 'sku' => $sku, 'description' => $product->description]];
            }

            $current = Product::find($item->product_id);
            $this->audit($epc, $sku, $product->id, 'conflict', $item->product_id, $item->id, $userId, $deviceId, $clientUuid,
                'EPC asignado a ' . ($current?->sku ?? '?'));
            return ['status' => 409, 'body' => ['result' => 'conflict', 'current_sku' => $current?->sku, 'current_description' => $current?->description]];
        });
    }

    public function lookup(string $epc): array
    {
        $epc = $this->normalizeEpc($epc);
        $item = PhysicalItem::with('product')->where('rfid_tag', $epc)->first();
        if (! $item) return ['status' => 'new'];
        $last = TagMatch::with('user')->where('epc', $epc)->whereIn('result', ['created','verified'])->latest('id')->first();
        return [
            'status' => 'assigned', 'product_id' => $item->product_id,
            'sku' => $item->product?->sku, 'description' => $item->product?->description,
            'assigned_by' => $last?->user?->name, 'assigned_at' => $last?->created_at?->toIso8601String(),
        ];
    }
    // private reject(): audit result 'rejected' with message, return ['status'=>422,'body'=>['result'=>'rejected','message'=>$msg]]
    // private replay(TagMatch $m): map stored result to same status/body (created→201, verified→200, conflict→409, rejected→422)
    // private audit(...): TagMatch::create([...])
}
```
Implement `reject`, `replay`, `audit` exactly as described in the comments (they are private helpers, write them fully).

```dart
// sku_parser.dart
final _skuRe = RegExp(r'^AF-\d{6}$');
String? parseSku(String raw) {
  var s = raw.trim();
  if (s.isEmpty) return null;
  final uri = Uri.tryParse(s);
  if (uri != null && uri.hasScheme && uri.queryParameters['term'] != null) {
    s = uri.queryParameters['term']!;
  }
  s = s.toUpperCase().replaceAll(' ', '');
  if (RegExp(r'^\d{1,6}$').hasMatch(s)) s = 'AF-${s.padLeft(6, '0')}';
  if (RegExp(r'^AF\d{6}$').hasMatch(s)) s = 'AF-${s.substring(2)}';
  return _skuRe.hasMatch(s) ? s : null;
}
```
Tests: URL `https://possible.conmebol.com/api/search?type=product&term=AF-012917` → `AF-012917`; `af-012918` → `AF-012918`; `12918` → `AF-012918`; `AF012918` → `AF-012918`; `hola` → null; empty → null.

```dart
// tag_picker.dart
class TagRead { final String epc; final double rssi; TagRead(this.epc, this.rssi); }
sealed class PickResult {}
class Picked extends PickResult { final String epc; Picked(this.epc); }
class NoTag extends PickResult {}
class Ambiguous extends PickResult {}
PickResult pickTag(List<TagRead> reads, {double marginDb = 3}) {
  if (reads.isEmpty) return NoTag();
  final sorted = [...reads]..sort((a, b) => b.rssi.compareTo(a.rssi));
  if (sorted.length > 1 && (sorted[0].rssi - sorted[1].rssi) < marginDb) return Ambiguous();
  return Picked(sorted[0].epc.toUpperCase());
}
```
Tests: empty → NoTag; one → Picked; two within 2 dB → Ambiguous; two 6 dB apart → Picked strongest.
